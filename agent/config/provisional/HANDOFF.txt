Calibration and units
The homography input is 1280x720 coordinates. Native camera capture is 1920x1080, so multiply BOTH pixel axes by 2/3 exactly once before applying H_pixel_to_xy. Divide homogeneous coordinates by the third component. Matrix output is meters. Multiply by 100 for the agent's centimeter fields.
To calculate yaw and width, transform the detected outline into the robot plane before fitting it. Define yaw as the long-axis angle atan2(dy,dx), degrees modulo 180. Motion must explicitly map this pack-axis convention to its jaw orientation.
Calibration was fitted on paper at table height. Pack height, camera distortion, ruler error, origin offset, and axis alignment remain physical error sources.
Fit RMS 1.56 mm and max 2.43 mm are agreement with ruler estimates, not demonstrated robot positioning accuracy. Held-out cross 2 error 0.45 mm; cross 9 error 4.68 mm.
Point images were read manually. Reconfirm reference marks against the current camera before enabling motion.

Boundary
Use the paper polygon for image detection and the candidate robot polygon for provisional diagnostics.
The candidate robot polygon is the convex hull of the nine references. It is not proof of robot reach.
Motion must provide the verified reachable polygon, clearance margin, hover/read/grasp heights, and feasible gripper orientation.
Require the grasp footprint to fit inside the verified polygon with clearance; test approach and path feasibility separately.
While motion_verified or execution_enabled is false, return no executable pack IDs. Provide provisional detections in a diagnostic channel with an explicit reason. Enforce the same check in inspect and sort.

agent/real.py
Replace occupied()/scan() fixed-slot background lookup with live OpenCV detection in the configured polygon.
Return stable IDs tied to a scan/frame revision, robot x_cm/y_cm, angle, width_cm, height_class, footprint, and timestamp.
The current detector rejects multiple candidates and misses foil overlapping the tape seam. Extend and validate multiple-pack association before claiming multi-pack support. Keep stale, ambiguous, occluded, or low-quality detections out of executable results.
Replace slot((x_cm,y_cm)) nearest-slot routing in pick with a target from the cached scan.
Replace crop(pack_id)'s slot read sequence with a motion-approved read approach to that target, then acquire a fresh full-resolution wrist image.
Verify placement with source disappearance AND destination evidence. Source disappearance alone is insufficient to confirm the correct bin.

agent/sorter.py
Remove the automatic in_reach=True for records with a slot.
Use shared eligibility checks for scan, inspect, and sort. Scan exposes only eligible IDs to Claude. Recheck the latest pose, freshness, boundary, calibration status and motion feasibility before acting.
Lookup the target by ID in executor-owned state. Claude should not supply arbitrary coordinates.
Keep unknown/expired/label rules independent of geometry checks.
Reject a target that moved since scan; request rescan and label confirmation rather than using stale coordinates.

agent/mcp_server.py
Keep scan -> inspect(id) -> sort(id,bin,reason,read_name).
Expose id, pose in cm/degrees, in_reach and scan revision in scan output.
Inspect returns wrist image inline. It can move the arm and must use the same eligibility gate as sort.
Claude reads the printed label and chooses the destination. Local code applies calibration and motion constraints.

Verification before enabling execution
- Offline: verify scale and units, polygon boundary cases, multiple packs, tape glare, empty scene, stale IDs, moved packs and camera bump.
- Confirm unsupported resolution or camera mismatch is rejected.
- Dry run: provisional profile must block movement from inspect and sort.
- Motion team: validate origin/axes and slow hover alignment at independent center/edge points, then record worst observed error.
- Update verified polygon, clearance and heights only from motion team's checks.

The supplied files are review artifacts. No live configuration or motion code was replaced, and no motors were commanded.
