# Changelog fragments

One file per PR, so two open PRs never conflict on `CHANGELOG.md`.

- Name: `YYYY-MM-DD-short-topic.md` (e.g. `2026-11-21-push-primitive.md`).
- Content: one bullet in the `CHANGELOG.md` style. Say what changed, the measured result (scene, seeds, numbers), and what is not verified.
- After the event, fold them into `CHANGELOG.md` (newest first) and delete them.
